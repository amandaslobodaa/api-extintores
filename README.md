# Sistema de Gerenciamento de Extintores

Back-end de um sistema web para gerenciamento de extintores, desenvolvido com Kotlin, Spring Boot e PostgreSQL, com API REST e autenticação JWT.

## Funcionalidades

- Cadastro e gerenciamento de extintores;
- Cadastro e gerenciamento de empresas;
- Cadastro e gerenciamento de localizações;
- Cadastro e gerenciamento de categorias;
- Cadastro e gerenciamento de movimentações;
- Gerenciamento de itens das movimentações;
- Autenticação de empresas com JWT;
- Validação de dados;
- Integração com banco de dados PostgreSQL.

## Tecnologias utilizadas

- Kotlin
- Spring Boot
- PostgreSQL
- Hibernate
- JWT
- API REST
